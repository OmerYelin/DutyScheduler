# 🛡️ Intelligence Duty Scheduler App

מערכת שיבוץ תורנויות חכמה לאגף מודיעין המבוססת על Gemini AI, אופטימיזציית עומסים ושמירת ניקוד מצטבר.

## 🚀 features
- פענוח אוטומטי של תמונות לוח תורנויות דרך Gemini 2.5 Flash API.
- אכיפת פטורים רפואיים, מנוחות 8 שעות, ואיסור רצפי שמירות/מטבח.
- מנוע ניקוד קושי מצטבר (Scale 1-4) הנשמר ב-LocalStorage.
- העדפות נסתרות אישיות לחברי הצוות.
- הפקת פָּקָשׁ מוכן להעתקה ל-WhatsApp.
